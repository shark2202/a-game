# 路由决策表（软件域 v0.1.2）

## 总路由（C1 出口）

```
目标进入（按交付局处理：<目标>）
 → 三问过目标 + goal-lock 三件套 + 注册表查重
 → 轻量通道初判：单 actor 可完成？零外部副作用？完全可逆？——三者全真 → 提交人类 T1 确认
    ├─ 轻量：单 actor + checklist + 照常登记 + fresh 抽查（抽样率显式）+ 校准（不设 M1–M4）
    └─ 全量：按下表定形态 → 03 模板成军 → M0–M4
```

## 全量通道组织形态表

| 项目性质 | 组织形态 | 角色配置 | 关键门 |
|---|---|---|---|
| 单模块、AC 清晰（如单文件工具、纯函数库） | **微型军** | coordinator + builder×1 + verifier(fresh) | goal-lock + fresh 终局验证；豁免 scout 与试点（见裁剪矩阵） |
| 多模块系统（典型软件项目） | **标准军** | coordinator + scout + builder×N + verifier(fresh) + hostile-reviewer(fresh) | scout 事实前置（T2 材料必附）；敌意审查 AOOS 设计；试点先行；波次验证 |
| 大型系统（模块 >6 或跨子系统） | **联邦军** | 标准军角色 + 子系统波次组 | **一次 T2 批准、一行登记**；子系统为军内波次组（各走试点与波次验证门，不另过 T2、不另占注册表行）；总 AOOS 持模块间接口契约 |
| 缺陷修复（对既有交付物） | **hotfix 军** | coordinator + builder×1 + verifier(fresh) | 复现脚本前置（先复现再修）；回归验证（原 AC 全量重跑）；豁免 scout 与试点 |
| 重构（行为不变的内部改写） | **重构军** | coordinator + builder×N + verifier(fresh) + hostile-reviewer(fresh) | 行为等价验证（重构前 AC 重跑基线）；试点＝首个等价验证切片；敌意审查必设 |
| 文档/知识生产（README、规范、报告） | **写作军** | coordinator + researcher×N + verifier(fresh) | 波次两波派发；引用核实（PAT-001）；锚点齐备；豁免 scout |
| 涉不可逆操作（部署/发布/数据迁移/删既有系统） | 任意形态 + **不可逆门** | 不变，仅加门 | T3b 不可逆审批队列（可批量，2 当量/轮）；演练（dry-run）一次通过；回退方案随批提交；能可逆则一律可逆（元层 §5.2「全程可逆操作」优先） |

**体型术语统一**：「中型以上」＝标准军与联邦军（敌意审查门必设的口径，与上表对应）；微型军/hotfix 军/写作军为「小型」。

## 形态×段裁剪矩阵（各形态对 M0–M4 的裁剪权威表；「试点波必为波 1」仅适用于带试点的形态）

| 形态 | M0 成军（含 scout） | M1 试点 | M2 批量 | M3 验收 | M4 学习 |
|---|---|---|---|---|---|
| 微型军 | scout 豁免（AC 清晰单模块） | 豁免（无批量可铺） | 单波 | fresh 全验 + T4 | 全 |
| 标准军 | scout 必做 | 试点波必设 | 多波 | fresh 全验 + T4 | 全 |
| 联邦军 | scout 必做 | 每波次组各设试点波 | 波次组并行 | 分组验收 + 总验收 | 全 |
| hotfix 军 | scout 豁免 | 复现脚本替代试点 | 单波 | 回归全验 + T4 | 全 |
| 重构军 | scout 必做 | 首个等价验证切片 | 分批 | 行为等价全验 + T4 | 全 |
| 写作军 | scout 豁免 | 首篇即试点（锚点规范回灌） | 两波 | fresh 锚点核验 + T4 | 全 |

**叠加规则**：任何豁免 scout 的形态一旦叠加不可逆门（涉部署/发布/迁移/删除），scout 转为**必做**（00 §3 M0.3）——不可逆操作的事实侦察（回退路径/演练可行性）不可省。

## 形态判定顺序（先特后普）

1. 涉不可逆操作？→ 叠加不可逆门（T3b）；
2. 对既有交付物的缺陷修复？→ hotfix 军；
3. 行为不变的内部改写？→ 重构军；
4. 纯文档/知识产出？→ 写作军；
5. 模块 >6 或跨子系统？→ 联邦军；
6. 多模块？→ 标准军；
7. 单模块且 AC 清晰？→ 微型军；
8. 判定不了 → 按更高形态走（宁全勿缺，代价只是多一道敌意审查）。
