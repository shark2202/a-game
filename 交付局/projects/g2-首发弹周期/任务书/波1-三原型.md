## 共同硬约束（T8——HOW 归你，以下是不可越的边界）

1. **零现金成本**：无外部付费资产；美术用 Canvas 程序绘制（几何/程序生成风格即可，原型阶段不追求美术质量）。
2. **浏览器直玩**：交付 `index.html` 双击即可玩（无构建链、无外部网络依赖）。
3. **核心与渲染分离（关键工程约束）**：游戏核心（规则/状态机/数值）在 `core.js`（纯 JS、不依赖 DOM），渲染层在 `index.html` 内加载 core。**目的：核心可在 node 下机器自测**。
4. **机器可测（verify-by-running）**：交付 `test.js`——`node test.js` 在无浏览器环境模拟 ≥100 局，输出：胜负分布、平均局时、埋点事件触发计数（与 core 埋点一致）；退出码 0/1 表示通过/失败。
5. **埋点**：session 开始/结束、局数、单局时长、失败重试次数（内存计数 + `window.__metrics` 导出接口 + test.js 可读取同一通道）。
6. **一局 2–5 分钟**；前 30 秒可上手（无教程或一句话教程）；难度曲线存在（core 参数可调）。
7. **玩法差异化**：可属既有品类族，但必须有 ≥1 个明确微创新点（在 README 用一句话讲清「与最近似的知名玩法的差异」）；**禁直接克隆知名玩法**（Apple 4.3 风险，R3§4）。
