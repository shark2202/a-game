# 引信合成 · Fuse Merge（槽 2 · 合成/连锁型）

## 钩子（一句话）

每步掉下来的新数字都拖着一根**点燃的短引信**——任何续命波都救不了它，烧完就炸成堵路的灰烬；你必须在总引信（全局步数预算）烧尽前，把它不断合并进金字塔、合成 8。

## 与最近似玩法的差异（≥1 个微创新点）

**最近似玩法：2048（滑动合并族）。** 差异一句话：2048 是纯空间资产管理（大块可以永久蹲在角落攒着），《引信合成》给每一个方块内嵌了倒计时——不持续合并就燃尽成障碍物、合并则通过续命波维持全场生命，把 2048 的「空间拼图」变成「合成速度 vs 燃烧速度」的攻防节奏：

- **新块短引信**：每步生成的块自带点燃的引信（`spawnFuse`），不受任何波保护，每步必烧一格——忽视它就变成灰烬障碍；
- **续命波/十字止燃/连锁止燃**：成型块每步燃烧，本步有合并则全场止燃，合并落点同行同列额外 +1，一步双合并则连锁止燃全场 +1（连锁奖励）；
- **灰烬攻防**：燃尽产物是不动、不融、切分压缩段的障碍（2 点耐久），而合并落点正交相邻的灰烬会被震碎——障碍的生成与清除都由玩家的合并行为驱动；
- **总引信**：全局步数预算收口单局时长（默认 180 步），杜绝 2048 后期的无限拖延。

（另：与 Threes 的差异——无卡牌手牌与 1/2 不可合并限制；与 Triple Town 的差异——全场滑动而非逐格落子。）

## 30 秒上手

1. 方向键 / WASD / 触屏滑动：全场滑动，相同数字相撞合并，**合成 8 获胜**；
2. 新块（橙色描边、底部彩条）每步烧短一格，烧完炸成灰烬——**尽快把它合掉**；
3. 合并发出续命波止燃（落点十字额外回复，一步双合并全场 +1），落在灰烬旁还会**震碎**它；
4. 顶部红条是**总引信**（步数预算），烧完或无路可走即负。

难度曲线参数全部集中在 `core.js` 的 `DEFAULTS`（`fuseMax` / `spawnFuse` / `stoneHP` / `targetLevel` / `maxSteps` / `spawnLevel2Chance`），见自检 [C] 段的参数扫描。

## 运行说明

- **浏览器直玩**：双击 `index.html`（零外部资产、零网络依赖、无构建链；美术全部由 Canvas 程序绘制）。R 键或「重开一局」按钮重开；埋点见控制台 `window.__metrics.getMetrics()`。
- **机器自测**：`node test.js`（node ≥ 14，本机 v24.16.0 验证通过），退出码 0 = 通过 / 1 = 失败。
- **核心与渲染分离**：`core.js` 为纯 JS 核心（规则/状态机/数值/埋点，不依赖 DOM，可在 node 下 require）；`index.html` 仅做渲染/输入/动画，通过 `window.FuseCore` 加载核心。
- **埋点通道**：内存计数 + `window.__metrics`（node 下为 `globalThis.__metrics`）导出接口；事件含 session 开始/结束、局数（game_start/game_end）、单局时长（durationMs，浏览器为真实时间，test.js 注入 1.2s/步虚拟时钟）、失败重试（retry = 败局后再次开局）。`test.js` [B] 段对同一通道逐项对账。
