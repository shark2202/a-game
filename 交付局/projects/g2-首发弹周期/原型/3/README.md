# 红限反应堆 Redline Reactor

> 槽 3（渐进/循环型 · idle 族）· G2-首个游戏发弹军 · builder-B3 · 波 1 原型

## 钩子（一句话）

**一局 4 分钟闭环的「骑红限」放置**：产出每秒自动上涨，升级让数字爬得更快但热量也涨得更快，而入库倍率随热量攀升（冷存 ×0.4 → 红热 ×2.1）——你必须故意把反应堆骑在熔毁边缘入库，赶在堆芯熔毁或班次超时前攒够 4800 单位。

## 与最近似玩法的差异（微创新点）

**最近似：Cookie Clicker 一族的长线 idle。** 差异一句话：经典 idle 是「无限游戏、耐心必胜、等待零风险」，本作把同一条数值爬升曲线改造成 **2–5 分钟内闭环的 push-your-luck 风险博弈**——爬升速度本身是风险源（产热 ∝ 产出），收益与危险共用同一个读数（热量越高入库倍率越高），核心循环是「爬升 → 骑红限 → 入库 → 排热」的节奏决策，而不是「买完等着」。三个具体机制差异：① 红热入库倍率（收益随危险度缩放）；② 排热泄压但浪费 25% 当前电力（安全有明确价格）；③ 局内「核心不稳定」难度曲线（t>100s 后产热持续 +45%/60s，拖得越久越危险）。

## 运行说明

- **浏览器直玩**：双击 `index.html`（零外部资产、零网络、无构建链；美术为 Canvas 程序绘制）。
  - 操作：`1`/`2`/`3`（或点按钮）= 加购 / 排热 / 入库；`Enter` 开始/重开。开始界面可选 难度（轻松/标准/严酷）。
  - 一句话教程见开始界面与页脚；30 秒内即可上手（只有 3 个键）。
- **机器自测**：`node test.js`（node ≥ 14 即可；本机 v24 验证）。120 局无浏览器模拟，退出码 0/1。

## 玩法速览（正常局 2–5 分钟闭环）

| 动作 | 效果 | 代价/风险 |
|---|---|---|
| 加购 STOKE | 产出 ×1.5 | 价格 ×1.9 上涨；**产热 ∝ 产出**，越买越烫 |
| 排热 VENT | 一次性泄掉 40+7×加购数 热量 | 冷却 5s；**浪费当前电力 25%** |
| 入库 BANK | 当前电力全额 ×倍率 转入金库 | 倍率 = 0.40 + 1.70×(热量/100)，**冷存重罚、红热 ×2.10** |

- **胜**：班次内（250s）入库 ≥ 4800；**负**：热量 ≥100 堆芯熔毁，或超时。
- 节奏起手：连按加购爬产出 → 热量逼近红线时「先入库再排热」（入库后电力归零，排热的 25% 损耗趋近于零）→ 循环。终盘在「再买一级」与「开始收割」之间取舍（bot 实测：贪进高等级线的专家被熔毁惩罚）。

## 难度曲线与参数可调

- **局内曲线**：`INSTABILITY_START=100s` 起，产热系数每 60s +45%（`INSTABILITY_RATE`）——前期宽松、终盘逼仓。
- **全部数值在 `core.js` 的 `TUNING` 导出**（目标/时限/价格曲线/产热/泄热/倍率带/不稳定速率），另有 `PRESETS`（easy / normal / hard）与 `createTuning(difficulty)`；浏览器与 node 共用同一份。
- bot 分布证明曲线有效：新手胜率 17%（超时为主）→ 熟练 100% → 贪进专家 73%（8/30 熔毁）→ 无脑莽夫 0%（熔毁为主）。

## 工程结构（核心与渲染分离）

```
core.js     游戏核心：规则/状态机/数值 + 埋点（纯 JS，无 DOM，node 可跑）
index.html  渲染层：Canvas 程序绘制 + 输入（加载 core.js，双击即玩）
test.js     自测：4 档 bot × 120 局无浏览器模拟 + 16 项交叉校验
README.md   本文件
```

- 埋点通道：内存计数对象 + `window.__metrics`（浏览器导出接口，含 live `counters` 与 `getMetrics()`）；node 侧 `core.getMetrics()` 读同一对象——**同一通道**。事件：`session_start / session_end / run_start / run_end / win / loss / meltdown / timeout / retry / stoke / vent / bank`；含每局时长数组与胜/负局时长统计。失败重试 = 上一局失败后的重开（`retry`）。
- 确定性：核心无隐藏随机；`test.js` 用种子 RNG（mulberry32），同种子两遍回放完全一致（校验项之一）。
