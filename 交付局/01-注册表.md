**使用规则**：
1. 成军前查重：读表，比对非 DONE 行目标是否同质（读取时点留痕于 AOOS 成军前检查栏）；
2. 批准即登记：加行（含 AOOS 指针列），状态 ACTIVE，成军耗时起点＝目标进入时间戳（C1 落盘值）；
3. 提交终审：状态 VERIFYING（Pre-Verified 报告已就位于 projects/<项目名>/验收报告.md）；
4. 人类终审：授 Verified → ACCEPTED → 学习闭环完成后改 DONE 并补记三字段 + Surprise Rate；否决 → REWORK（连续 2 轮 REWORK 自动升级 T3a 并标记验收僵局，00 §3 M3.4）；
5. 安全停机：运行中组织触发停机条件或 AC 级变更受影响波次 → HALTED，恢复后续行；目标侧停靠（未成军）为 PENDING；
6. 轻量通道同样登记（通道列记「轻量」，一行一任务，登记后按显式抽样率 fresh 抽查，校准后即闭环）。

**并行治理挂钩**（00 §4 与 06 账本）：**在航上限＝本表 ACTIVE+REWORK+VERIFYING 行数合计 ≤3**（默认，candidate；PENDING 不占——尚未成军；ACCEPTED 不占——终审已过仅待学习闭环）。超限时新目标停靠 PENDING。
